# れきしパズル(日本の歴史の年表パズル)

時代・人物・出来事のカードを、たての年表(上が昔、下が今)の正しい番号にはめていくスマホ向けWebアプリ(PWA)。

- 公開URL: https://kamedono213.github.io/rekishi-puzzle/
- 種類
  - 時代(15): 縄文〜令和
  - 人物(42): 小学校学習指導要領(平成29年告示)第2章第2節 社会 第6学年「内容の取扱い」(2)ウ で例にあげられている42人。よみも同じ資料のふりがな
  - 出来事: 中学生レベル24、高校生レベル+22(年号つき)
- モード(人物・出来事): かんたん=年表に時代名(出来事は年も)が出る/むずかしい=時代名も年もなく位置だけ
- 年が近いもの(1800年より前は8年以内、それより後は2年以内、同じ時代の中)は、どちらの番号に入れても正解にしている(位置だけでは区別できないため)。ビルド時に組み合わせを表示する
- 年表の時代の帯は、見やすいように同じ高さにしている(実際の長さとはちがう)。帯の中では年の位置に番号を置く
- ヒント(何回でも使える。星はへらない): ちいき(時代と、答えがある範囲の丸)/とくちょう/2つにしぼる

## 出典と確認
- 人物42人: 文部科学省「小学校学習指導要領(平成29年告示)」PDF の 61ページ(研究用に research/pdftext.mjs で文字を取り出して確認)。ウィキブックスの一覧には藤原頼通を含む43人が載っているが、原文には藤原頼通はない
- 年号: 教科書で一般的な年(鎌倉幕府は源頼朝が征夷大将軍になった1192年、室町幕府は足利尊氏が征夷大将軍になった1338年として人物・出来事のヒントに書いた)
- 小学生レベルの文に、4年生までに習わない漢字がふりがななしで残っていないかを機械で確認

## 作り方
- `data/items.txt` … 出題リスト
- `node tools/build-data.js` … `app/data/rekishi.json`
- `node tools/make-icons.js` / `node tools/build-pages.js` … アイコン / `docs/`
- `node serve.js docs` … http://localhost:5395 で確認
